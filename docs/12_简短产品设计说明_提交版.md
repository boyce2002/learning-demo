# 微光实验室 SparkLab｜简短产品设计说明（提交版）

**在线体验：** 尚未生成公网 URL；代码与部署清单已通过本机生产形态验收，等待仓库与 Render 账号授权后创建服务。  
**作品类型：** 面向学生的五分钟主动学习 Web Demo。  
**数据声明：** 题目为人工预置；演示时间舱中的学习日期和成长记录可模拟，不代表真实学生数据，也没有使用 AI 自动评分。

## 为什么这样设计

普通打卡容易把注意力放在“有没有完成”或“答对了多少”。SparkLab 把一次五分钟学习设计成完整的小循环：**先提出猜想，再查看解释，最后用自己的话表达收获**。一屏只处理一个阶段，降低开始门槛；温和但诚实的反馈允许学生猜错，不把错误包装成正确，也不因错误中断学习。

## 如何提升主动性

系统奖励的是学习行为，而不是正确率：学生必须先做判断才能揭晓，必须写下 6–120 字符的真实反思才能点亮星星。连续星轨鼓励再次开始，星光手记把抽象天数变成可以回看的个人表达。长期效果仍属于产品假设，尚未经过真实学生实验验证。

## 主要实现

React + TypeScript + Vite 负责逐步交互、断网保留输入、移动端和键盘体验；FastAPI 负责题目、猜想、完成、进度和历史接口；SQLite 通过事务与唯一约束保证首次猜想锁定、每日完成幂等和 streak 统计。

公网 Demo 使用同域 HTTPS：FastAPI 同时托管前端静态资源与 `/api`。后端为每个浏览器签发不可预测、HMAC 签名的匿名会话 Cookie（`HttpOnly`、`Secure`、`SameSite=Lax`），所有读写按已验证访客 ID 隔离。模拟日期只改变当前访客的演示参考日；“重置我的体验记录”只删除该访客数据，全局开发 reset 在公网不注册。

## 建议体验路线

开始探索 → 选择一个猜想 → 查看积极且诚实的反馈 → 留下一句话收获 → 点亮星星 → 刷新确认恢复 → 用演示时间舱完成 D、D+1、D+2 → 在 D+4 查看 streak 归零但累计保留 → 打开星光手记回看三条反思。

核心表达：**SparkLab 奖励的不是答题正确率，而是学生主动提出猜想、理解知识并表达收获的学习行为。**
