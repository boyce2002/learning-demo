# SparkLab｜在线 Demo 评审体验指南

**公网链接：** 待云平台授权并通过 HTTPS 复验后填写。  
**请先知悉：** 页面题目为人工预置；演示时间舱中的学习日期和成长记录可模拟，不代表真实学生数据。每个浏览器通过匿名签名 Cookie 获得独立体验记录，不是账号系统。

## 最短体验路线（约 2–3 分钟）

1. 用新的无痕窗口打开 HTTPS 链接，确认顶部出现模拟数据声明，成长星轨从当前匿名访客的空白状态开始。
2. 点击“开始今天的探索”，选择一个猜想，再点击“揭晓答案”。刻意猜错也可以继续；重点看系统明确说明差异，同时不给惩罚性反馈。
3. 点击“写下今天的发现”，输入至少 6 个字符的真实一句话收获，点击“点亮今天的星星”。确认连续/累计变为 1。
4. 刷新页面，确认完成状态与原反思恢复。这一步证明数据来自真实后端写入，不是前端假加一。
5. 在“演示时间舱”依次选择“+1 天”“+2 天”，各自走完同一流程。确认第三天 streak 为 3、累计为 3。
6. 选择“+4 天”。这是明确标注的模拟日期：因为中间漏一天，streak 应归零，但累计仍为 3。
7. 点击“查看我的星光手记”，确认三条反思按日期倒序出现；按 Escape 关闭，焦点应回到手记按钮。
8. 如需重新体验，点击“重置我的体验记录”。它只清除当前匿名访客，不能清除其他评审的数据。

## 建议解说

> SparkLab 奖励的不是答题正确率，而是学生主动提出猜想、理解知识并表达收获的学习行为。这里切换的是明确标注的模拟日期，只用于展示连续学习机制；每条猜想、反思和完成记录仍通过真实后端写入，并与其他匿名访客隔离。

## 独立访客快速复核

同时打开两个新的无痕窗口 A/B：

- A 完成一天后刷新，应恢复完成状态。
- B 不应出现 A 的反思，累计仍为 0。
- A 执行“重置我的体验记录”后，B 的状态不得变化。
- `/api/dev/reset` 和 `/docs` 在公网应返回 404。

若任一项不符合，不要继续向评审宣称数据隔离已通过。

## 演示前准备

- 提前访问 `/api/health`，确认 200；只预热页面，不预写学习记录。
- 使用新的无痕窗口，避免上次 Cookie 让页面已完成。
- 预备三句不同反思，但必须通过 UI 正常提交，不直接修改数据库或统计结果。
- 不把模拟日期称为真实自然日学习，不说“真实学生已经连续学习三天”。
- 网络较慢时等待按钮恢复，不重复点击；失败时页面会保留选择/反思，可恢复后重试。
- 不开放公共全局 reset，不展示平台密钥、Cookie、数据库文件或控制台隐私信息。

## 仍需真人检查

- 一台真实手机上的触控、滚动和软键盘遮挡。
- NVDA 或 VoiceOver 的标题、状态、dialog 与错误朗读顺序。
- 公网首次冷启动、不同网络地区延迟，以及云平台真实重启后的 SQLite 恢复。
