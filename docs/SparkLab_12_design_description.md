# 微光实验室 SparkLab｜Demo 设计说明

**在线体验：**【部署后填写真实可访问的 HTTPS Demo 链接】  
**作品类型：**面向学生的五分钟主动学习 Web Demo  
**数据说明：**本 Demo 使用人工预置的 7 道微挑战题目与匿名体验数据；「演示时间舱」中的日期用于模拟跨天学习，以便展示连续学习机制，不代表真实学生的长期学习表现，也没有使用 AI 自动评分。

## 为什么这样设计

传统每日打卡容易让学生只关注“是否完成”，而忽略主动思考。SparkLab 把每天五分钟设计为一个完整的微探索过程：**发现问题 → 独立猜想 → 查看解释 → 用自己的话总结 → 点亮成长星星**。一屏聚焦一个任务，降低开始学习的心理负担；柔和的星空视觉和及时反馈，让探索过程轻松、积极。

## 哪一点能够提升学习主动性

最重要的是**先猜想，再揭晓，最后表达自己的收获**。学生必须先主动做出判断，系统才给出知识解释；即使猜错，也会得到明确而鼓励性的反馈，而不是被惩罚。完成后的成长星轨展示连续学习天数，星光手记保留过去的反思。这既鼓励学生每天开始，又帮助他们看见自己积累的思考，而不是仅仅刷正确率。上述机制属于产品设计假设，尚未通过真实用户实验验证其长期学习效果。

## 主要实现方式

使用 **React + TypeScript + Vite** 构建响应式学习界面，**FastAPI** 提供今日任务、猜想提交、完成反馈、成长进度和历史手记接口，**SQLite** 持久化记录。服务端负责首次猜想锁定、每日完成幂等、连续学习天数计算；前端负责逐步交互、刷新恢复、请求失败后的重试和移动端适配。**在线部署要求：**正式公开访问前需为每位访客建立独立匿名会话、隔离学习记录，确保模拟日期仅影响该访客；此项仍需开发并在线验收，不能把本地封版结果视为已经上线。

## 建议体验路线

点击“开始探索” → 选择一个猜想 → 查看反馈 → 写下一句话收获 → 完成并点亮星星 → 查看学习进度。若展示了演示时间舱，可继续模拟连续三天及漏学后的星轨变化。
