# SparkLab 60–90 秒演示脚本

录制前只在本机按 README 开启 `DEMO_MODE=true` 与 `DEMO_RESET_ENABLED=true`。页面上的数据是固定演示用户模拟记录。以录制当天首次加载的北京时间日期为基准日 D，使用时间舱的“今天 / +1 天 / +2 天 / +4 天”，即 D、D+1、D+2、D+4；不要长期硬编码 2026-11-05。这样所有镜头天然处于后端以真实当天为中心的 ±30 天允许窗口。

录制前检查：先重置隔离的本机演示记录；确认页面明确显示“演示用户/模拟数据”；确认 D、D+1、D+2、D+4 均可加载；关闭浏览器缓存或旧标签页造成的干扰。公开环境不得开启 reset。

| 时间 | 画面与操作 | 旁白重点 |
|---:|---|---|
| 0–8 秒 | 打开首页，展示当日真实映射的微挑战、0 天星轨和“演示模式”标记 | “这是微光实验室：每天五分钟，从一个真实猜想开始。” |
| 8–20 秒 | 点“开始今天的探索”，选择一个错误选项并揭晓 | “系统先保存第一次判断；不是答题扣分，而是让思考有起点。” |
| 20–32 秒 | 展示“猜想不同”、正确答案与当天的人工预写知识解释 | “反馈会诚实说明不同，也给出可理解的原因。” |
| 32–45 秒 | 写下至少 6 字反思并点亮星星 | “只有留下自己的理解后才完成；进度来自后端，不会提前加一。” |
| 45–53 秒 | 刷新页面 | “刷新仍恢复完成状态、原反思和第一颗星，因为数据已写入 SQLite。” |
| 53–69 秒 | 用演示时间舱切到 +1、+2 天，各完成一次（录制可剪辑） | “同一套真实接口模拟连续三天，streak 变为 3。” |
| 69–80 秒 | 切到 +4 天，展示漏一天后的 streak=0、累计仍为 3 | “连续天数诚实归零，但累计学习不会消失。” |
| 80–90 秒 | 打开“星光手记”查看三条只读反思 | “数字最终变成可回看的知识痕迹，而不是一张排行榜。” |

录制完成后可点击“重置演示记录”恢复空数据库。公开环境不要启用 reset；如果不做匿名会话隔离，优先提交本演示视频而不是共享可写链接。

正式录制请使用 `docs/10_正式演示分镜与解说词.md`；本文件保留为现场快速提示版。D+1、D+2 的完成必须通过真实 UI 写入后端，成片可剪掉重复输入和等待，但不得手改 SQLite 或前端统计。
